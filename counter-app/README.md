# Counter App

A simple React application built with Vite that demonstrates a basic counter UI. The app lets users increase, decrease, and reset a counter value using a custom React hook.

## Features
- Display the current count
- Increase the count
- Decrease the count without going below zero
- Reset the count to zero

## Tech Stack
- React
- Vite
- Tailwind CSS

## What i learn
- Use State Hook
- File Structure

## Getting Started
1. Install dependencies:
   npm install
2. Start the development server:
   npm run dev
3. Open the local URL shown in the terminal

## Scripts
- npm run dev: start the development server
- npm run build: create a production build
- npm run preview: preview the production build
- npm run lint: run ESLint
